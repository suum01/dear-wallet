# Dear Wallet

나에게 맞는 가계부. 기록은 가볍게, 내 돈의 흐름은 또렷하게.

AI가 소비 내역을 자동 분류하고, 소비 습관 분석과 맞춤형 예산 관리를 도와주는 개인 가계부 웹앱을 목표로 합니다. 현재 구현 범위는 아래와 같습니다.

연노란색과 세이지 그린, 직접 그린 지갑 캐릭터로 구성한 반응형 홈입니다. 외부 폰트·CDN·애플리케이션 의존성 없이 실행됩니다.

## 실행

Node.js 22 이상(검증: 24.22.1).

```sh
npm start
```

기본 포트는 3000이며 `PORT=3001 npm start`로 변경할 수 있습니다. 정적 호스팅 시 `index.html`, `src/`, `favicon.svg`, `manifest.webmanifest`를 함께 배포합니다. 경로는 도메인 루트 기준입니다. 서버는 개발용이며 공개 서비스의 인증·데이터 서버가 아닙니다.

## 구현한 것

- 모바일 하단 메뉴 / 데스크톱 사이드바, 320px부터 대응하는 홈
- 예산 전에는 가득 찬 원과 지출 금액, 예산 후에는 12시에서 시계 방향 사용률
- 전체 예산, 기간 경과, 남은 일수, 아직 결제되지 않은 고정비를 제외한 가용 금액
- 수동 지출·수입·내부 이체 기록, 월급날/달력 집계, 기간별 전체 예산, 고정비 연결
- 한국 시간 기준 일별 금융 상식 7개 순환, 북마크, JSON 내보내기
- 실제 기록과 분리된 샘플 둘러보기(설정에서 시작)
- 접근 가능한 다이얼로그, 키보드 포커스, 모션 감소 설정 반영

첫 실행은 0원에서 시작합니다. 예시 금액은 **설정 → 샘플 데이터로 둘러보기**에서만 표시합니다. 내역·돌아보기 메뉴는 후속 구현 예정임을 안내하며, 예산 메뉴는 현재 전체 예산/고정비 설정창을 엽니다. 자동 분류는 아직 없으며 기록은 미분류로 보관됩니다.

## 데이터 안내

현재 데이터는 `localStorage`의 `dear-wallet.v1`에만 저장됩니다. 서버 전송·로그인·기기 동기화가 없습니다. 브라우저 데이터 삭제/기기 변경 시 보존되지 않으므로 설정에서 JSON으로 내보내세요. 파일 복원 UI는 후속 작업입니다. 내보낸 파일에는 개인 기록이 들어 있으므로 저장소에 커밋하지 마세요. 저장에 실패하면 완료로 처리하지 않고 기존 데이터를 보호합니다. 샘플 모드의 수정은 실제 기록에 반영되지 않습니다.

고정비는 등록한 전체 예상 금액을 예약하고, 같은 집계 기간의 지출에 연결되면 예약에서 제외합니다. 부분 결제·고정비 변경 이력·환불은 아직 지원하지 않습니다. 고정비 예정일은 향후 캘린더 표시를 위한 정보이며 날짜가 지났다고 자동 결제 처리하지 않습니다.

## 검증

```sh
npm run check
npm test
```

선택적 브라우저 통합 검증은 Python Playwright와 시스템 Chromium이 있는 환경에서 실행합니다. 애플리케이션 실행에는 필요하지 않습니다.

```sh
# 별도 터미널에서 npm start 실행 후
python tests/browser.py
```

`CHROMIUM_PATH`로 브라우저 경로를 변경할 수 있습니다. 320/375/390/430/768/1024/1440px 화면, 기록·새로고침 저장, 예산 사용률, 고정비 중복 차감 방지, 수입/이체 제외, 샘플 격리, 초과 예산, 기간 변경, 큰 금액을 검사합니다. 화면 캡처는 Git에서 제외된 `artifacts/`에 생성됩니다.
