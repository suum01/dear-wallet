# Dear Wallet

**카테고리 고민은 줄이고, 내 돈의 흐름은 직접 기록해요.**

Dear Wallet은 모바일과 PC에서 사용하는 개인 가계부 웹앱입니다. AI 자동 분류로 기록의 부담을 줄이고, 나에게 맞는 한 달 기준으로 수입과 지출을 돌아봅니다.

👉 **[웹앱 사용하기](https://suum01.github.io/dear-wallet/)**

로그인 전에도 샘플 데이터로 둘러볼 수 있습니다.

## 사용하기

1. 웹앱에서 **Google 계정으로 시작하기**를 누릅니다.
2. 처음이라면 한 달의 기준을 선택합니다.
3. 수입과 지출을 기록합니다. 예산은 나중에 설정해도 됩니다.

**일반 사용자는 Firebase 프로젝트 생성, API 키 발급, Google Sheets 연결 없이 사용할 수 있습니다.** 운영자가 연결한 Firebase 프로젝트에서 로그인과 계정별 저장을 처리합니다. 같은 Google 계정으로 로그인하면 모바일과 PC에서 기록을 이어서 사용할 수 있습니다.

## 주요 기능

| 기능 | 내용 |
|---|---|
| **Google 로그인** | 같은 계정으로 모바일과 PC에서 기록을 이어서 사용 |
| **간편한 기록** | 수입·지출에 맞춘 입력 화면, 기록 수정·삭제·실행 취소 |
| **AI 자동 분류** | 사용처·입금처와 내용을 해석하고, 필요한 새 카테고리를 추천 |
| **직접 선택** | 수입·지출별 전체 카테고리 목록에서 선택하거나 직접 입력 |
| **예산 관리** | 예산 사용률 원그래프, 남은 예산, 고정비를 고려한 가용 금액 |
| **달력** | 날짜별 수입·지출 합계와 상세 기록 바텀 시트 |
| **돌아보기** | 전체 요약, 카테고리별 원그래프와 금액·비율, 기간 조회, 카테고리 상세 내역과 수정·삭제 |

## 기록과 집계 원칙

- **달력 기준 또는 월급날 기준**으로 한 달을 설정합니다.
- **내 계좌 간 이체는 합계에서 제외**하고, 다른 사람에게 보낸 돈은 용도에 맞는 지출로 기록합니다.
- **직접 고른 분류를 우선**하며, 새 카테고리는 사용자가 확인한 뒤 추가합니다.
- AI에 연결할 수 없을 때도 임시 분류나 직접 선택으로 기록할 수 있습니다.

## 저장과 AI 사용

로그인한 계정의 기록은 Firebase를 통해 기기 간에 동기화합니다. 사람마다 별도의 계정 경로에 저장하며, 접근 권한은 로그인한 계정을 기준으로 구분합니다. 화면에서 저장·동기화 상태를 확인할 수 있으며, JSON 파일로 내보내기도 지원합니다.

AI 분류에는 사용처·입금처, 내용, 거래 종류와 추가한 카테고리 이름을 사용합니다. 작성한 지출 이유와 입금 경위 메모는 AI 분류 입력에 포함하지 않습니다.

Google Sheets 연결은 선택 기능입니다.

## 개발용 로컬 실행

이 절은 소스를 수정하거나 직접 별도 서비스를 운영하려는 개발자를 위한 안내입니다. 배포된 Dear Wallet을 이용하려면 위의 웹앱 링크에서 Google 로그인하면 됩니다.

Node.js 24 사용을 권장합니다.

```bash
git clone https://github.com/suum01/dear-wallet.git
cd dear-wallet
npm ci
npm run dev
```

기본 실행 주소는 `http://localhost:3000`입니다.

직접 별도 서비스를 운영하는 경우, **운영자가 한 번** Firebase 프로젝트와 Google 로그인·Firestore·AI Logic을 설정합니다. 이용자마다 프로젝트를 만들 필요는 없습니다. 자세한 방법은 아래 상세 문서를 참고하세요.

### 검증과 빌드

```bash
npm test
npm run check
npm run build
```

인증과 AI 응답을 사용하는 자동 브라우저 검증은 모의 어댑터로 진행합니다. 실제 서비스 연결은 운영자가 프로젝트 환경에서 별도로 확인합니다.
