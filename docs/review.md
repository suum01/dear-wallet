# 돌아보기: 요약·원그래프·상세 내역·기간 비교

총수입·총지출·수입−지출, 카테고리별 지출/수입 도넛, 기간 선택과 카테고리 상세 내역, 지난 기간 비교를 제공한다. `#review` 주소와 모바일/데스크톱 메뉴에서 열 수 있다. 기존의 연노란색·연녹색 카드와 지갑 화면 톤을 유지한다.

## 집계 기준

- 홈과 같은 `getPeriod`를 사용한다. 달력 기준은 1일~말일, 월급날 기준은 설정일~다음 설정일 전날이다. 없는 29~31일은 해당 달 말일로 보정한다.
- 진행 중인 기간은 한국 시간 오늘까지 기록한 내역만 포함한다. 과거 기간은 해당 기간 전체를 보여준다. 다음 기간 버튼으로 현재 기간을 넘어갈 수 없다.
- 삭제한 기록·내 계좌 간 이체는 수입/지출에서 모두 제외한다. 다른 사람에게 보낸 돈을 지출로 기록한 경우 포함한다.
- 고정비의 미결제 예상액을 다시 더하지 않는다. 실제로 지출 기록한 금액만 포함한다. 주식 등 카테고리 이름으로 거래 종류를 바꾸지 않는다.
- 수입−지출은 두 합계의 차액이며 실제 계좌 잔액을 뜻하지 않는다.
- 이름이 비어 있거나 없는 지출 분류는 미분류, 수입 분류는 기타 수입으로 집계한다. 사용자 추가 분류와 현재 목록에 없는 예전 분류도 저장된 기록의 이름으로 표시한다.
- 차트 비율은 각 거래 종류의 합계가 분모다. 수입과 지출의 금액을 한 원그래프에 섞지 않는다.

## 차트와 기간 이동

- 모바일은 두 카드를 위아래로, 넓은 화면에서는 나란히 배치한다. 중앙 총액, 기록 수, 카테고리별 정확한 원 단위 금액과 비율 표를 함께 제공한다.
- 6개 이하 카테고리는 모두 표시한다. 그보다 많으면 큰 5개와 ‘나머지 N개’로 모으고, ‘카테고리 모두 보기’로 펼친다. 실제 ‘기타’ 분류를 임의로 합치거나 원본 데이터를 변경하지 않는다.
- 각 차트의 펼침 상태는 독립적이다. 날짜나 집계 기준을 바꾸면 접힌 상태로 돌아간다.
- 0원 차트는 빈 안내와 회색 원을 보여준다. 0으로 나눠 비율을 만들거나 가상의 지출·수입을 채우지 않는다.
- 아주 작은 항목도 금액을 보존하며 비율은 ‘0.1% 미만’으로 표시할 수 있다. 억 단위 이상인 중앙 표시만 ‘약 N억 원’으로 줄이고 표와 전체 요약에서는 정확한 금액을 보여준다.
- 색만으로 구분하지 않도록 이름·금액·비율 표를 제공한다. 카테고리 이름은 HTML로 해석하지 않는다.
- 이전/다음 기간, 이번 기간 이동과 페이지 탐색·다시 그리기는 가계부 데이터를 저장하거나 바꾸지 않는다. 기록 수정·삭제·계정/시트 동기화는 기존 render 경로로 즉시 반영한다.
- 새 기록은 돌아보기 상단의 ‘기록하기’를 사용한다. 모바일에서 중복되는 떠 있는 기록 버튼은 이 화면에서 숨겨 그래프를 가리지 않게 한다.
- 계정 종료·교체 시 조회 기간과 차트 펼침 상태를 초기화하고 이전 사용자의 금액·분류를 지운다. 인증 전에는 기존 로딩/로그인 보호를 유지한다.

## 카테고리 상세 내역

- 원그래프 조각 또는 카테고리 표의 항목을 누르면 바텀 시트가 열린다. 키보드로도 조각/항목을 선택할 수 있고, 닫으면 선택했던 항목으로 초점이 돌아간다.
- 선택한 기간·수입/지출 종류·카테고리를 적용해 날짜가 최신인 기록부터 보여준다. 상단에는 조회 기간, 합계, 건수를 표시하고, 각 기록에는 사용처/입금처·날짜·분류·내용·이유를 표시한다. 조회만으로 데이터나 AI 요청을 만들지 않는다.
- ‘나머지 N개’는 실제 묶인 분류들의 기록을 연다. 같은 이름의 사용자 카테고리와 구별하며, 수정 중 차트 순위가 바뀌어도 열어둔 묶음의 구성은 유지한다.
- 기록을 누르면 기존 수정 화면으로 이동한다. 저장·취소·삭제 후 같은 기간과 카테고리 상세로 돌아오고, 홈·돌아보기 합계와 차트는 최신 데이터로 갱신한다.
- 날짜·종류·카테고리를 바꾼 기록은 원래 조회 조건에 맞지 않으면 목록에서 빠진다. 마지막 기록이 사라져도 빈 안내를 보여주며, 삭제한 경우 시트 안에서 실행 취소할 수 있다.
- 기록이 없어져 원래 카테고리 버튼도 사라졌다면 차트 제목으로 초점을 돌린다. 다른 메뉴로 이동하거나 계정을 종료·교체하면 상세 조회 상태와 내용을 지운다.

## 지난 기간과 비교

- 원그래프 아래에서 선택한 기간과 바로 이전 기간의 총지출·총수입, 차액과 변화율을 보여준다. 지출 변화는 카테고리별 금액 차이를 기준으로 늘어난 항목과 줄어든 항목을 각각 최대 3개씩 보여준다. 동일한 차액은 이름순으로 정렬한다.
- 현재 기간은 한국 시간 오늘까지, 이전 기간은 시작일부터 같은 경과일까지 비교한다. 예를 들어 달력 기준 11월 9일에는 11월 1~9일과 10월 1~9일을 비교한다. 월급날 25일 기준이라면 10월 25일~11월 9일과 9월 25일~10월 10일을 비교한다.
- 이전 기간이 더 짧으면 실제 마지막 날까지만 집계하고 두 구간의 일수 차이를 표시한다. 완료된 과거 기간을 선택하면 두 기간 전체를 비교하고, 달마다 일수가 다를 수 있음을 안내한다. 화면에 실제 집계한 시작일과 종료일을 표시한다.
- 수입·지출은 독립적으로 계산하며 내 계좌 간 이체·삭제·미래 기록은 제외한다. 미분류·사용자 추가 분류·예전 분류도 차트와 같은 이름 기준으로 집계한다. 증가액은 양수, 감소액은 음수로 계산하고 화면에는 금액과 증가/감소 문구를 함께 표시한다.
- 이전 금액이 0원이면 변화율을 계산하지 않고 ‘이전 0원’을 표시한다. 양쪽이 같으면 ‘변화 없음’, 아주 작은 변화율은 ‘0.1% 미만’으로 표시한다. 이전 구간에 수입·지출 기록이 모두 없으면 0원 기준임을 알린다. 기록 누락이 결과에 영향을 줄 수 있음을 안내한다.
- 카테고리 항목을 누르면 기존 상세 바텀 시트에서 ‘선택 기간 / 이전 기간’을 전환할 수 있다. 양쪽 목록은 비교에 표시된 정확한 날짜 범위를 사용한다. 선택 기간에 기록이 사라진 카테고리는 이전 기간을 먼저 연다. 일반 원그래프 상세는 기존처럼 선택한 전체 기간을 사용한다.
- 상세에서 수정·삭제·실행 취소하면 비교 금액·순위와 차트도 갱신한다. 수정·취소 후 보고 있던 쪽과 날짜 범위를 유지한다. 순위 변화로 버튼이 다른 변화 목록으로 옮겨가면 그 버튼으로 초점을 돌리고, 상위 3개에서 빠지면 비교 제목으로 돌아간다.
- 조회·기간 전환만으로 저장하거나 AI를 호출하지 않는다. 계정을 종료·교체하면 비교 금액과 목록도 초기화한다.

## 후속 단계

이유 분석, 카테고리 예산 비교, 월간 리포트·회고는 아직 구현하지 않았다. 잔액 대조도 별도 후속 기능이다.

## 검증

```sh
npm test
npm run check
npm run build
npm run preview
# 다른 터미널
BASE_URL=http://127.0.0.1:4173/dear-wallet/ python tests/review-browser.py
BASE_URL=http://127.0.0.1:4173/dear-wallet/ python tests/review-detail-browser.py
BASE_URL=http://127.0.0.1:4173/dear-wallet/ python tests/review-comparison-browser.py
BASE_URL=http://127.0.0.1:4173/dear-wallet/ python tests/history-browser.py
BASE_URL=http://127.0.0.1:4173/dear-wallet/ python tests/auth-browser.py
```

단위 검증은 홈 합계 일치, 종류별 비율, 미분류·사용자 분류, 삭제·이체·미래 제외, 윤년·월급날 경계, 항목 묶기, 상세 조건·정렬·합계와 원본 불변, 비교 날짜 범위·짧은 달 보정·0원 기준·변화 순위를 확인한다. 브라우저 검증은 격리된 가상 기록으로 320~1440px 화면, 실제 그래프 터치·키보드·초점 복귀, 상세에서 수정·삭제·취소·실행 취소, 비교 양쪽 전환과 이전 기록 수정, 기간 기준 변경, 직접 경로 새로고침, 큰 금액·안전한 이름 표시를 확인한다. 계정 분리는 모의 Firebase 어댑터로 확인하며 실제 사용자 계정 기록이나 AI API는 사용하지 않는다.
